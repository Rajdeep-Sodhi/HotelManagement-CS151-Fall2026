# CS151-Hotel_Management
An OOP introductory project based on a UML class diagram with a user interface using scanner in the console that follows a hotel management theme. 

## Recent UI Changes

- Added role-based login for guests, employees, and managers.
- Added account creation after selecting a role.
- Guests can make reservations, check in, check out, and view reservations.
- Accounts and reservations are stored only during the current program run.
